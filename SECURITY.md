# Security Policy

## Reporting a Vulnerability
Please open a private security advisory or email security@ghas-security-lab.example.
We aim to acknowledge reports within 2 business days.

## Supported Versions
We support the latest minor release of each active major version.

## Security Configurations
- Code scanning via CodeQL
- Dependabot alerts and security updates enabled
- Dependency Review enforced on business-critical repositories
- Secret scanning with push protection

## Contact & Triage
Security team: security@ghas-security-lab.example
